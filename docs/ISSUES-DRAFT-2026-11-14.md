## Issue-04　翻页笔特殊键适配

**标题**：`[R-04] 翻页笔特殊键适配：拦截 / 映射 / 提醒弹窗`

**背景**
部分翻页笔的特殊键会误触 ICC 的快捷键，导致老师在课堂上意外触发批注、黑屏、退出放映等。需要一个可配置的适配层。

**目标**
在 PPT 联动模式下，接管这些特殊键，让它们按老师期望的方式工作，或明确拦截。

**范围**
新增模块：`Helpers/FlipPen/`、`Windows/SettingsViews/Pages/FlipPenPage.xaml`、OOBE 新增一步。

**详细需求**

前置条件：**PPT 联动模式下持续抢占焦点**（实现方式待确认）

可配对功能与默认键：
| 键 | 功能 |
|---|---|
| Ctrl+P | 打开/开启批注 |
| E | 清空批注 |
| B | 黑屏 |
| Shift+F5 | 放映/退出放映 PPT |
| ESC | 退出放映 |

**不开启时**
- 只拦截，不响应
- 按 B / ESC / Shift+F5 时弹窗：
  - 说明该键的作用
  - 提示可能是误触翻页笔特殊键，或按压到翻页键
  - 两个选项：「继续拦截此键」/「我没有误触，需要此功能」
  - 选「需要」→ 开启适配，该键按映射工作
  - 选「继续拦截」→ 不开启、不再通知、继续拦截；同一个键后续不再弹窗

**开启时**
按映射正常工作。

**配置入口**
- OOBE 必须新增
- 设置页也可配置
- 都要能录入/重新配对按键
- 文案要教老师：怎么触发特殊键、怎么录入

**视觉**
统一设计语言、分组卡片、按键录入态、冲突提示、深浅色适配、面向教师的文案。

**验收标准**
- [ ] OOBE 里有翻页笔设置步骤
- [ ] 设置页能开启/关闭、能重新配对 5 个键
- [ ] 不开启时，按 B/ESC/Shift+F5 弹窗，两个选项都按描述工作
- [ ] 选「继续拦截」后，同一个键再按不弹窗
- [ ] 开启时，5 个键按映射工作
- [ ] 深浅色下弹窗和设置页都正常

**影响版本**：0.1a

**测试步骤**
1. 进 OOBE，找到翻页笔设置，录一个键
2. 设置页开启/关闭开关，各试一次
3. 关闭状态下按 B，看弹窗
4. 选「继续拦截」，再按 B，确认不弹
5. 开启状态下按 B，确认黑屏
6. 依次试 ESC、Shift+F5、E、Ctrl+P

**关联需求**：R-04、R-02（视觉一致）

**附件**：无

**待确认（本 Issue 阻塞最多）**
- **Q4-1/2/3 拦截层级：焦点+RegisterHotKey 还是全局钩子（⛔ 阻塞，决定会不会影响其他程序）**
- Q4-4 不弹窗是本次会话还是永久
- Q4-5 弹窗样式规范
- Q4-6 为什么只有 3 个键弹窗
- Q4-7 重新配对是替换还是可清空
- Q4-8 配成同一功能时冲突怎么处理
