## P0-3 电脑操作插件验证 ⏳

**结论：部分可用，有明确限制。**

| 能力 | 状态 | 说明 |
|---|---|---|
| 读取 ICC 窗口真实像素 | **不可靠** | `MainWindowHandle = 0`，常规截图 API 拿不到 |
| 把 ICC 窗口提到前台 | **不可靠** | `WS_EX_NOACTIVATE`，`SetForegroundWindow` 无效 |
| 合成鼠标点击 | **可用但要验证落点** | 上次教训：点在浏览器上 |
| 读窗口句柄 | 需 EnumWindows 枚举 | PrintWindow 对 WPF 合成层无效 |

**结论：PPT / 笔迹这类功能测试不能只靠模拟点击，必须结合日志 + 程序内自测。**
