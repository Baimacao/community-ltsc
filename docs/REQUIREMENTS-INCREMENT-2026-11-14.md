## R-04　翻页笔适配（本批最大项）

### 背景（用户原话）
> 部分翻页笔特殊键会触发快捷键。

### 前置条件
**PPT 联动模式下持续抢占焦点。**

### 可配对功能与默认键
| 按键 | 功能 |
|---|---|
| Ctrl+P | 打开/开启批注 |
| E | 清空批注 |
| B | 黑屏 |
| Shift+F5 | 放映/退出放映 PPT |
| ESC | 退出放映 |

### 两种状态的行为

**不开启时**
- 只**拦截**这些键，不响应
- 但按下 **B、ESC、Shift+F5** 时弹美观弹窗：
  - 提醒该键的作用
  - 说明可能是**误触翻页笔特殊键**或**按压到翻页键**
  - 询问：「继续拦截此键」还是「我没有误触，需要此功能」
- 选「需要此功能」→ 自动开启翻页笔适配，该键按映射工作
- 选「继续拦截」→ 不开启、不通知、继续拦截；**后续同一个键不再弹窗**

**开启时**
- 按配对映射正常工作

### 配置入口
- **OOBE 必须新增该设置**
- 设置页也可配置
- 都要能**录入或重新配对按键**
- 文案要告诉老师：怎么触发特殊键、怎么录入

### 视觉要求
设置页与弹窗都要：
- 统一设计语言
- 分组卡片
- 按键录入态
- 冲突提示
- 深浅色适配
- 文案面向教师

### 待确认
- [x] **Q4-1/2/3** 拦截层级 → **已答复：只在 PPT 联动时生效**。不开启时不做全局影响，仅 PPT 联动模式下接管。实现细节（RegisterHotKey vs 钩子）由实现方定，前提是不影响 PPT 联动之外的操作。
- [ ] **Q4-2** 「Ctrl+P」等的拦截层级：全局键盘钩子（影响全系统）还是仅在 ICC 聚焦时？
- [ ] **Q4-3** 拦截用 `WH_KEYBOARD_LL` 全局钩子还是 `RawInput`？全局钩子会影响老师的其他操作
- [ ] **Q4-4** 「后续同一个键不再弹窗」——是本次会话不弹，还是永久不弹（写进配置）？
- [ ] **Q4-5** 弹窗的样式规范：沿用项目现有的什么对话框？（iNKORE ContentDialog？自绘？）
- [ ] **Q4-6** 只有 B/ESC/Shift+F5 弹窗，Ctrl+P 和 E 为什么不弹？确认这是有意设计
- [ ] **Q4-7** 按键录入时如何「重新配对」——录到的新键替换默认值，还是可以清空？

## R-05　ClassIsland 联动

### 目标
做一个 CI 插件与 ICC CE Lite 通信。

### 详细需求
1. **性能优化**：自动读取 CI 课表，使用**专门课表交换格式**（智教联盟里有相关内容）；每节课下课后**自动回收句柄与内存**
2. **擦黑板**：
   - 上课时清空**批注模式**与**白板模式**的笔迹
   - **PPT 模式不要删**
   - **连堂不删**
3. **触发器**：在 CI 自动化中加入
   - 进入批注状态
   - 进入白板状态
   - 进入 PPT 联动状态
   - 以上三个状态**退出时也要有返回值**，告知已取消状态
