# ICC CE Lite

> 从 InkCanvasForClass Community Edition 分出的独立分支。
> 目标只有一个：**在教室的触摸屏上稳稳跑完一节课。**

上课的时候，白板卡一下，四十分钟就没了。这个分支所有改动都围着这一条转：
不是加功能，是把会出事的地方一个个摁住。

| 项 | 值 |
|---|---|
| 当前版本 | `0.1c-daily`（后缀带提交号，形如 `0.1c-daily+4d4f6e3`） |
| 程序名 | `ICCCELite.exe`（和原版可以装在同一台机器上） |
| 上游基线 | `083f694e`（InkCanvasForClass/community，2026-07-15） |
| 目标框架 | .NET 11（`net11.0-windows10.0.19041.0`） |

---

## 这个分支做了什么

### 稳定性

一节课越上越卡、长课后半段笔迹发飘、改完设置重启全丢——这些不属于「偶尔卡一下」，
是会让课上不下去的。

| 问题 | 影响 |
|---|---|
| 退出后残留 `InkCanvas.IACoreHelper.exe` | 反复开关机攒出好几个后台进程，越跑越慢 |
| 跨线程访问 `DynamicRenderer` 的判据只认英文 | 非英文系统上形同虚设，该拦的没拦住，可能直接崩 |
| 墨迹转形状每笔漏一个内核句柄 | 批注得越久句柄越涨，总有一天开不了新的 |
| 500ms 定时器跨进程枚举全屏窗口，没有重入门闩 | **一节课越上越卡的元凶** |
| PPT 墨迹的 COM 调用和整目录读盘都压在锁里 | 插墨迹那一下界面会顿住 |
| 配置清理把用户存的设置当「过期属性」删掉 | 改完重启就回滚，日志里还看不出是谁干的 |

### 触摸屏

这条是硬伤：软件是为触摸屏做的，可有些地方只有鼠标才点得到。

| 问题 | 影响 |
|---|---|
| 设置页缺 `PanningMode` | 平板上滚不动，等于进得去出不来，设置根本改不了 |
| 交互依赖鼠标悬停（hover） | 手指没有 hover，这类功能在触摸屏上从来没触发过 |

### 翻页笔

| 问题 | 影响 |
|---|---|
| 适配开启时按键被响应两次 | 黑屏黑两遍，退出一次退好几步 |
| 裸 ESC 注册成全局热键 | 把整个系统的 ESC 抢了，别的程序收不到 |
| 按键配对只存在内存里 | 改完键重启就没了 |

### 设置与多语言

- 四套语言：简体 `zh-CN`、繁体 `zh-TW`、梗体 `zh-ME`、英文 `en-US`
  基准 1323 键，三个译文各 1317 键（差的那几条是只在中文里出现的开发者名单）
- 设置区从 25 页压到 24 页，导航重新分组
- 清掉一批点了没有任何反应的开关（遥测等级、更新前备份、PPT 调试探针等）

### 主动移除的东西

下面这些是**故意删的**，不是漏了：

| 移除 | 原因 |
|---|---|
| 自动更新 | 整套功能移除，只留下「识别旧版启动参数」和「清理残留目录」两件事 |
| 遥测与隐私协议 | 代码里根本没有上传逻辑，协议描述的是已经不存在的能力 |
| 插件市场 | 依赖的服务已经下线 |
| 点名（随机抽人） | 边界不清，功能整体移除 |

## 自己编译

需要 .NET 11 SDK。

```bash
cd "Ink Canvas"
dotnet build InkCanvasForClass.csproj -c Release -p:Platform=x64
```

产物在 `bin/Release/x64/net11.0-windows10.0.19041.0/`。

**打发布包只放 10 个程序文件。** 输出目录里有四十多个文件，其余全是 Costura 会内嵌进主程序的，
或者运行时才生成的。哪些该进、哪些不该进，见 [docs/BUILD.md](docs/BUILD.md)。

### 冒烟自测

```bash
./ICCCELite.exe --smoke-test
```

结果写进 `Logs/Log_*.txt`，搜 `[探针]`。当前 **56 项全过，0 失败**。

这东西不是摆设：它检查的是「缓存有没有真的生效」「错误有没有真的记下来」这类
光看代码看不出来的事。改完代码跑一遍，比盯着屏幕猜靠谱。
